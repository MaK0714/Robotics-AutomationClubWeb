# Robotics and Automation Club - Static Website

A high-performance, modern static website for the **Robotics and Automation Club**. Built using **React + Vite + Tailwind CSS + Lucide Icons** with a sleek pure black dark-theme aesthetic and **Roboto** typography.

---

## Features

- **Pure Static Frontend:** Zero backend required. Outputs static assets ready for GitHub Pages, Netlify, Vercel, or Firebase Hosting.
- **Sticky Navbar:** Clean glassmorphism header with logo, smooth-scrolling anchor links, and mobile-responsive drawer menu.
- **Hero / Header Section:** Dynamic robotics title, key stat counters (Innovators, Robots, Awards), and quick action CTAs.
- **Pillars & About:** Mission, vision, and the complete hands-on engineering cycle (CAD → PCB → Firmware → Testing).
- **Technical Wings:** Division breakdown covering Mechanical/CAD, Embedded Systems, Autonomous ROS 2, Computer Vision/Edge AI, and IoT Automation.
- **Engineering Portfolio:** Showcase of flagship club robots with filter categories (Rovers, Manipulators, Drones, Automation).
- **Events & Workshops:** Schedule for bootcamps, hackathons, and guest seminars.
- **Interactive Join Form:** Static onboarding form and lab contact/meeting schedule.
- **Sticky / Responsive Footer:** Social links, sub-team directories, and live lab status indicator.

---

## 🛠️ Tech Stack & Dependencies

- **Framework:** React 18
- **Build Tool:** Vite 5
- **Styling:** Tailwind CSS 3
- **Icons:** `lucide-react`
- **Font:** Google Fonts Roboto (`font-sans`) and Roboto Mono (`font-mono`)

---

## Getting Started

### 1. Run Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 2. Build for Production (Static Output)
```bash
npm run build
```
The compiled, optimized static HTML, CSS, and JS bundles will be in the `dist/` directory.

### 3. Preview Static Build
```bash
npm run preview
```
